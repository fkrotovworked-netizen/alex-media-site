# Alex Media — сайт digital-агентства

Сайт агентства Alex Media (Александр Гирин): digital-маркетинг, AI и автоматизация.
Общение с заказчиком — на русском.

**Сначала прочитай [HANDOFF.md](HANDOFF.md)** — там текущее состояние, что утверждено и что делать дальше.

## Запуск

```bash
npm run dev -- --port 5183     # или preview_start с именем alex-media (.claude/launch.json)
npm run typecheck
npm run build
npm run assets                 # пересобрать вырез формы, карту кромки и зерно из логотипа
npm run bits -- Имя            # поставить компонент React Bits из реестра (--check — только зависимости)
npm run covers                 # скачать недостающие обложки кейсов с CDN ВК в public/cases/ (webp)
```

## Стек — и чего в нём нет

Vite + React 19 + TypeScript + обычный CSS с токенами. **Motion (`motion/react`) — единственный motion-движок.** Чистый WebGL2.

Не подключать: Tailwind, GSAP, Lenis, three, ogl. `framer-motion` в дереве — это ядро самого Motion, не второй движок.

## Дизайн-система — не нарушать

Утверждена заказчиком на первых двух секциях («это ахуенно, продолжай»).

- **Свет один.** Ключевой источник сверху-слева; курсор двигает свет и камеру, а не отдельные элементы. От него зависят блики формы, кромка стекла, ободки кнопок (`--light-angle`), подсветка заголовка.
- **Материалы и роли:** графит — земля (~85% площади); чёрный акрил — мелкие контролы и панели; Liquid Glass — редкий, только фокус и навигация; lime — свет и одно главное действие на экран.
- **Lime — свет, а не краска.** Никаких lime-заливок блоков и glow вокруг. Тон замерен по логотипу (66–71°): `#E4F929 → #C1E507 → #AACC03 → #859E04 → #516306`.
- **Шрифты:** Unbounded 500–560 (заголовки, отрицательный трекинг по размеру), Onest (текст), Martian Mono (мелкие подписи).
- **Движение:** пружины с критическим демпфированием (`src/motion/tokens.ts`, параметры в виде damping/response). Bounce нигде. Нажатие отвечает на pointer-down. Цвет и прозрачность — короткий ease, всё, что движется, — пружина.
- **Не три карточки в ряд.** Один лист, разделённый фасками.
- **Светлые секции — листы** (`Sheet`), тёмные стоят на графите. Чередование — по ТЗ заказчика.
- **Цифры не выдумывать.** Неподтверждённое помечать «уточнить» или «демо».
- **Anti-slop:** перед показом пройти чек-лист — не шаблон ли, не много ли glow и стекла, не дешёвый ли lime, есть ли иерархия.

## React Bits — обязательное правило заказчика

Перед каждой сложной визуальной задачей смотреть reactbits.dev: демо, исходник, зависимости. Затем по приоритету:

1. наша существующая motion-система;
2. компонент React Bits, адаптированный под неё (ставить через `npm run bits`, править на месте, в шапке файла писать «что оставлено / что изменено»);
3. своё.

Компонент на GSAP / three / ogl либо переписывается, либо не берётся. Сайт не должен выглядеть витриной React Bits. После каждого этапа — отчёт по 7 вопросам (что найдено, что использовано и почему, что переписано, что не взято, новые зависимости, нет ли второго motion-движка).

## Проверка

Панель браузера уменьшает скриншоты до ~800×500 — по ней нельзя судить о стекле и типографике. Полноразмерные снимки:

```bash
node tools/shoot.mjs имя "http://localhost:5183/?t=3.2" 1440 900 1 --wait 2600
# флаги: --scroll y · --mouse x,y · --rm (reduced motion) · --eval "js"
# результат в tools/shots/ (в .gitignore); после прокрутки не использовать --clip
```

Скрипт берёт `puppeteer-core` из соседнего проекта `../CINEMATIC PRESENTATION` и системный Chrome.

Переключатели в адресе: `?t=1.2` — заморозить вход, `?fps`, `?rm`, `?nogl`.

Проверять на 1440×900, 1920×1080, 390×844 и в состояниях прокрутки. Контраст текста на стекле ≥ 4.5:1. Кадры — `tools/perf.js` (hero и плита) и `tools/perf-sections.js` (всё ниже) через `--eval "$(cat tools/perf-sections.js)"`.

## Прочее

- Исходный логотип `Логотип и айдентика.jpg` (на деле PNG с альфой) не трогать.
- Git: ветка `main`, репозиторий на GitHub (публичный). Каждый пуш в `main` пересобирает сайт на GitHub Pages (`.github/workflows/pages.yml`), адрес — в HANDOFF. Не коммитить и не пушить без просьбы.
- Пути к файлам из `public/` в коде — только через `asset()` из `src/asset.ts`: на Pages сайт живёт в `/<repo>/`, и голый `/brand/…` там не откроется. В CSS `url()` и в `index.html` абсолютные пути Vite переписывает сам.
- Соседние проекты в `../` не менять.
